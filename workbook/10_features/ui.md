# UI and visual features

Presentation and interaction elements enhancing usability.

## Themes

Dark, Light, High Contrast, platform variants, automatic system dark/light switching, custom theme extension via plugins (CSS).

## Layout

Responsive single‑page layout adapting to desktop and mobile. Sidebar (groups, tags, vaults), entry list (list or table view), details pane. Panels are resizable; state remembered.

## Icons and visuals

Built‑in and custom entry icons, automatic favicon retrieval for URLs, optional colorful icons, improved modern icon set.

## Mobile and PWA

Touch‑friendly layout, homescreen installation, orientation handling, iOS/Android PWA optimizations, appropriate virtual keyboard types for fields.

## Entry display

Masked protected fields with reveal/copy actions, inline password generator, attachment preview (including images), markdown notes rendering.

## Interaction aids

Keyboard navigation across lists and fields, context menus, drag‑and‑drop with visual cues, tooltips, inline editing, quick search focus.

## Accessibility basics

High contrast theme, scalable font size, focus indicators, reduced motion and locale‑aware dates.

## Status indicators

Per‑vault modified, syncing, error states in footer; search and filter indicators; lock state icons.

## Plugin surface

Themes and UI extensions injected via validated plugin manifests (details in stack files, not repeated here).
